# YouEDA CLI 1.4.0

First real release of YouEDA-CLI, replacing the previous `third_party/YouEDA` MSBuild
file-linking scaffold with a real, independently buildable CLI. Version number matches
[YouEDA](https://github.com/youprint/YouEDA) desktop's own 1.4.0 release, since the two
share the same forked conversion engine.

## What's in this release

- Real engine, forked from `YouEDA`'s `Services`/`Models` into `engine/`: EasyEDA/LCSC fetch
  and parse, native symbol resolution (bundled 71-symbol catalog, polarity-verified diode/
  transistor matching, discrete network topologies), and native Altium `.PcbLib`/`.SchLib`
  export. See MIGRATION_PLAN.md for the full file-by-file breakdown.
- `--input <bom.csv>`: import a flat LCSC part-number list.
- `--category`/`--catalog`: filter a local LCSC catalog export by category, manufacturer,
  package, part-class, and electrical parameters (resistance, capacitance, inductance,
  voltage, tolerance, power, dielectric, mounting), plus repeatable `--contains`/`--exclude`.
- `--with-3d`: opt-in STEP model download.
- `--resume`/`--checkpoint`: a completion ledger and periodic checkpointing survive `Ctrl+C`
  without duplicating completed parts.
- A live terminal progress bar (percentage, counts, throughput, ETA) in an interactive
  console, falling back to plain periodic text lines when output is redirected.
- Structured JSON-lines error log (`.youeda-bulk/errors.jsonl`) for failed parts.
- 26 automated tests: BOM parsing, catalog filtering, the ported symbol-correctness policies
  against the exact identities documented in `YouEDA`'s `AGENTS.md`, and the progress bar's
  render logic.
- CI (`build-and-test`) on every push/PR.

## Verified against live data

A full run against the 351-part JLCPCB Basic Parts BOM: 351/351 succeeded, 0 errors.
Measured throughput: ~58 parts/minute cold cache (bottlenecked by the shared 1 request/second
fetch gate), ~600 parts/minute warm cache. See README.md's Performance section.

## Known limitations

- Windows only, matching `YouEDA` desktop.
- `--rps` is currently informational; the fetch rate gate is fixed at 1 request/second.
- `--with-3d` has been manually verified but has no automated test yet.
- No KiCad export (Altium only, matching this CLI's original documented scope).
- Export-side geometry/checkpoint correctness tests (beyond the symbol-policy layer) are not
  yet ported from `YouEDA`'s `tests/KiCadSmoke` — see ROADMAP.md's Phase 4 entry.

## Install

Download `YouEDA-CLI-1.4.0-win-x64.zip` from this release, extract it, and run
`YouEDA.CLI.exe --help`. Requires the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
on Windows 10/11 x64. Verify the published SHA-256 checksum before use. See README.md's
Package section to build this yourself from source.
